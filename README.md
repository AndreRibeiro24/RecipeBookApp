
📖 Recipe Book App 
A simple and intuitive app to store, manage, and organize all your favourite recipes in one place.

✨ Features

Add Recipes — Upload and save new recipes to your personal collection Edit Recipes — Update ingredients, instructions, or any recipe details at any time Delete Recipes — Remove recipes you no longer need Recipe List — Browse all your saved recipes in one organized view
